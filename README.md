# 每日新闻收集器

零成本、零依赖、可长期运行的新闻聚合工具。抓取免费 RSS 源，按你的兴趣关键词过滤、去重、排序，生成 Markdown 日报和一个网页看板。

**不消耗任何 API 额度，不需要订阅，做完就一直能用。**

核心特点：**重要的事不会漏**。报告分三层：

| 层级 | 内容 | 怎么来的 |
|---|---|---|
| ★★ 必看 | 央行政策、CPI、美联储、全会、大选等硬新闻 | 标题命中必收关键词，绕开所有过滤 |
| ★ 要闻 | 权威源当天的其他新闻 | 来自中国新闻网、统计局、美联储等 |
| 主题 | 你的兴趣内容 | 36氪、IT之家等按关键词筛选 |

前两层保证不遗漏，第三层才是按兴趣筛的。

## 两种运行方式

| | 本地 | GitHub 云端 |
|---|---|---|
| 电脑关机 | 不跑 | **照跑，一天抓 5 次** |
| 国际新闻 | **抓不到**（境外源被墙） | **能抓**（服务器在国外） |
| 手机看日报 | 不方便 | **打开网址就行** |
| 邮件推送 | 支持 | 支持，早晚各一封，手机电脑同时收 |
| 适合 | 临时补抓 | 日常自动 |

**推荐直接上云端** → 看 [GITHUB-SETUP.md](GITHUB-SETUP.md)。

> 实测：纽约时报、BBC、卫报在国内网络全部超时，美联储和 SEC 能通。
> 所以国际新闻必须靠 GitHub 服务器抓，本地跑只能拿到国内内容。

下面是本地运行方式。

## 三步开始用（本地）

**1. 装定时任务（只需一次）**
双击 `install-task.bat` → 右键"以管理员身份运行"

装好后每天 **08:30** 自动抓取，日报存到 `reports/` 文件夹，文件名是日期。

**2. 想立刻看效果**
双击 `run-now.bat`

**3. 想改关注什么**
用记事本打开 `config.yaml`，改完保存即可，不用动代码。

想看网页版：双击 `run-now.bat` 之后，用浏览器打开 `docs/index.html`。

## 怎么调整你的兴趣

打开 `config.yaml`，三个地方最常改：

### 加关键词
```yaml
科技与产业:
  weight: 3          # 数字越大，这类新闻排得越前
  keywords:
    - AI
    - 芯片
    - 你的新关键词   # 加在这里
```

### 加信息源
```yaml
feeds:
  - name: 某某媒体
    url: https://example.com/feed
    topic_hint: 科技与产业
    enabled: true
```

### 收窄时间范围
```yaml
hours_window: 30     # 只看最近 30 小时。改成 12 就是半天
```

### 调整「保证不漏」的范围

这是最该关注的部分。`config.yaml` 顶部有 `must_watch.keywords`，
列在那里的词一旦出现在标题里，这条新闻就会被强制放进「今日重点」，
不管它有没有命中你的兴趣词，也不受任何过滤规则影响。

```yaml
must_watch:
  keywords:
    - CPI              # 现在已有的
    - 降准
    - 你想保证不漏的新词   # 加在这里
```

**判断标准：** 出现在这里的关键词只在**标题**匹配。因为正文里顺带提一句的
（比如财报里说"按证监会规定披露"）不算真的讲这件事，标题命中才算。

**想更保险？** 把某个源标成必收源，它的内容就全部进重点区：

```yaml
feeds:
  - name: 某权威媒体
    url: https://example.com/feed
    tier: must        # 加这一行
    enabled: true
```

改完直接双击 `run-now.bat` 验证。

## 每条新闻都带正文摘录和原文链接

RSS 里给的常常只有一句导语（"中新网北京10月26日电（记者 xxx）…"），所以程序会打开原文页面，
把正文前几段抓下来放在标题下面，最多 300 字，按句号截断。摘要本来就够长的就不再抓，省时间。

每条固定格式：

```
一句标题（可点开原文）
来源 · 时间 · 命中的必收词
正文摘录两三句……
同题另报：其他也报道了这件事的媒体（链接）
```

相关参数在 `config.yaml` 的 `enrich:` 段：

```yaml
enrich:
  enabled: true
  min_chars: 150      # 摘要短于这个字数才去抓原文
  target_chars: 300   # 抓到后留多少字
  max_items: 60       # 单次最多抓多少条（控制运行时间）
  workers: 6          # 并发数，太高容易被网站限流
```

## 同一件事只出现一次

同一件事经常被同一家媒体写成好几条（"卢拉将第四次出任巴西总统"/"外媒：巴西总统卢拉赢得连任"/
"外交部：中方祝贺卢拉在巴西总统大选中获胜"），标题相似度只有 0.3，靠字面比对合并不掉。

程序因此改成比对"两条标题共有的原文片段"：去掉"外交部""表示""发生"这类官话套话后，
同一家媒体共享 4 个字以上的实体片段（"巴西总统"）就判为同一事件，合成一条，
其余来源收在"同题另报"里——**内容一条不丢，只是不再重复占版面**。

不同来源之间判定更严格（要共享 6 字以上），避免把同一主题的两条不同新闻合并掉。
另外数字对不上的标题永不合并，所以"紫光国微净利 10.45 亿"和"长川科技净利 17.65 亿"不会互相吃掉。

英文源（BBC、纽约时报）单独放在"外媒原文"区，因为中英文没法自动比对，
混在中文里会显得同一件事出现了两次。

## 条数控制

```yaml
limits:
  max_per_feed: 8     # 中文权威源每个源最多先列几条（其余折叠）
  max_per_topic: 12   # 每个兴趣主题最多先列几条
  max_per_feed_en: 5  # 英文源每个源最多先列几条
  mail_must: 20       # 邮件里必看最多几条
  mail_level1: 12     # 邮件里要闻最多几条
  mail_interest: 8    # 邮件里兴趣最多几条
  mail_body_chars: 180  # 邮件里每条正文最多多少字
```

超出的部分不会丢：日报里折叠在"展开其余 N 条"里，邮件里提示去网页版看。

## 开启邮件推送（可选）

用记事本打开 `config.yaml`，改这一段：

```yaml
email:
  enabled: true                    # 改成 true
  smtp_host: smtp.qq.com
  smtp_port: 465
  sender: 你的邮箱@qq.com
  password: "邮箱授权码"            # 注意：不是 QQ 登录密码
  receiver: "手机@qq.com,电脑@outlook.com"   # 多个用逗号分隔
```

**QQ 邮箱授权码怎么拿：** 登录 QQ 邮箱 → 设置 → 账户 → 开启"IMAP/SMTP 服务" → 按提示获取授权码（16 位字母）。

用 Gmail 的话把 `smtp_host` 改成 `smtp.gmail.com`，端口 `465`。

## 程序会自己处理这些事

- **重要新闻漏掉**：三层分级 + 必收源 + 必收关键词，绕开所有过滤
- **RSS 只保留几十条**：所以一天抓 5 次，每次结果累积到当天日报，避免上午的新闻被晚上挤掉
- **源失效了**：自动跳过，继续抓其他的，日报末尾会列出哪个源挂了
- **境外源连不上**：连续 3 个失败就跳过剩余境外源，本地跑不用干等
- **同一件事多家报道**：自动合并成一条，标注"多家报道"，一天能省掉十几条重复
- **评论、纪录片、图解**：不算新闻，自动过滤，避免稀释重点区
- **昨天看过的**：自动跳过，只显示新增的
- **今天没新内容**：保留已有日报，不会覆盖成空白
- **一天跑多次**：后一次自动累加，不会因为某个源临时失败而丢掉前面抓到的内容
- **旧日报太多**：自动清理 90 天前的

## 常见问题

**Q：电脑关机了还会跑吗？**
本地跑法不会。开机后如果错过了 08:30，双击 `run-now.bat` 手动补一次即可，
程序会抓最近 30 小时的内容，不会漏。

想关机也照跑 → 看 [GITHUB-SETUP.md](GITHUB-SETUP.md)。

**Q：会不会哪天突然收费？**
不会。RSS 是公开协议，不需要密钥、不计次。代码只用 Python 标准库，没有任何第三方依赖需要付费。

**Q：想加某个特定网站怎么办？**
找它的 RSS 地址（一般在网站底部或 `/feed`、`/rss` 路径），加到 `feeds` 里。加完双击 `run-now.bat` 看能不能抓到，抓不到说明该站不提供 RSS。

**Q：分类不准怎么办？**
程序靠关键词判断主题。如果某条归错类，通常是关键词太宽泛。
`config.yaml` 里的 `weak_keywords` 就是用来治这个的——列在那里的词只在标题出现时才算命中。

**Q：怎么停掉？**
双击 `uninstall.bat` 删除本地定时任务。GitHub 那边在 Actions 页面点 Disable workflow。
